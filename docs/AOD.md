# 手机常显（AOD）使用说明

> 本文对应 PC 1.12.4 / Receiver 0.19.2（代码 44）。常显仍为预览功能，未完成实机长期验收。

## 1. 它是什么

AnPod 的“常显”是一个**伪 AOD**：全屏、纯黑、横屏，显示时钟、真实 PCM 波形和可选英文指标。参数居中并用 `|` 分隔。

- 它**不是**厂商在真正息屏/低功耗显示驱动里的原生 AOD，不接管锁屏，也不申请锁屏覆盖。
- 屏幕实际保持点亮（`FLAG_KEEP_SCREEN_ON`），OLED 黑色像素不发光，但仍会耗电。
- 锁屏、按电源键或退出后，常显不会自动重新出现；音频服务继续运行。

## 2. 如何开启

1. 手机打开 AnPod Receiver，开启 **“屏幕常显”** 可在接收时自动进入。
2. 点 **“进入常显”** 可立即进入；“常显设置”可调整字号、线宽和监控项。静态预览与实际布局等比缩放，线宽三档为约 0.5×、1×、2×。设置保存在手机本地。
3. PC 正在把声音播放到手机时，手机在前台会自动进入常显；退出后本次会话不再自动弹出。
4. 退出常显：
   - 点右上角“Close”；
   - 或下拉通知，点 **“打开常显”** 重新进入（开关开启时该动作才会出现）。

右侧区域上下滑动可调整手机媒体音量：上滑增大、下滑减小，操作时显示系统音量条；也可继续使用实体音量键。手势从第一段滑动就生效（没有起步延迟），约 60% 的区域高度即可走完整个音量范围。

在 PC 上切换“均衡 / 低延迟”会重建接收会话，其间几秒没有 PCM；这不会关闭常显，新会话会继续沿用同一个常显页面，不会退出重进。

PC 建立连接、切换播放模式或停止接收时，不再在手机上弹出白色的“管理服务”页面：这些操作现在直接启动/停止 Receiver 前台服务，界面保持在主界面或常显上。

**PC 端没有 AOD 开关**，是否显示完全由手机控制，也不新增任何控制协议。

## 3. 指标口径

| 指标 | 含义 | 不可测时 |
| --- | --- | --- |
| 状态 | `Connected` / `Receiving` / `Reconnecting` / `Not connected` | `Not connected` |
| Protocol | `USB Direct` / `UDP` / `ADB` | `—` |
| Recv | 当前窗口中认证通过的音频 payload 比特率 | `—`（尚无统计） |
| Buffer | 接收端可观测的待播放 PCM 缓冲，不是端到端延迟 | `—` |
| Loss | UDP 实际缺帧率：`concealed / (accepted + concealed)`；PLC 补偿帧算缺失，迟到过期/本地主动丢弃不算 | USB/ADB 恒为 `—` |
| Format（可选） | 实际输出采样率与声道 | `—` |
| Output（可选） | 实际输出引擎 `Oboe` / `AudioTrack` | `—` |
| Underruns（可选） | 可观测的播放欠载次数 | `—` |

后三项默认关闭；原四项监控默认开启，连接状态始终保留。

指标按整项换行，每行均匀展开至可用宽度，`|` 位于相邻指标之间；单项保持居中。

数字静音仍会持续收到零值 PCM，所以“静音”不会让 Recv 变成 `—`，也不会误报 0% 丢包；波形会回到中心直线。

## 4. 显示与省电

- 所有背景为 `#000000`，不使用 Material 暗色灰面、elevation 或 tonal overlay。
- 常显遵从系统亮度，包括系统自动亮度；烧屏漂移让时钟、波形和底部指标栏作为一个整体缓慢移动（横向约 ±16dp、纵向约 ±9dp，周期 120/150 秒），整屏没有长期静止的文字。
- 右上角“Close”在约 6 秒无触摸后淡出，触摸任意位置恢复；淡出期间不响应点击，避免误触退出。
- 双线波形位于时钟与底栏之间，振幅随可用空间调整（本版约为上一版峰值的 2/3），从中央向两侧缓慢传播，两端逐渐淡出；小音量声音也有清晰起伏，静音恢复直线。
- 两条曲线分别是立体声的左右声道，共用同一条基线（没有文字标记），右声道做了反相处理：即使左右声道此刻播放完全一致，也会一条向上、一条向下，不会叠成一条线。
- 波形是 PCM 驱动的艺术化包络，采用弱信号增强，仅供视觉展示，不代表声学测量。
- 已有有效会话连续中断约 15 秒才会退出常显；仅无 PCM、但会话仍在时保持显示。切换播放模式的短暂会话重建不会触发退出。
- 长时间常亮有 OLED 烧屏与耗电风险，首次使用请留意。
- 字体为 Rubik（SIL Open Font License 1.1），许可证见 `LICENSES/Rubik-OFL.txt` 和 APK 内 `assets/licenses/Rubik-OFL.txt`。

## 5. 已知限制

1. **后台自动进入受限**：Android 10+ 限制后台启动 Activity。手机 App 不在前台时，目前不会自动弹出常显；可从通知“打开常显”进入。后续版本再评估通知兜底。
2. **锁屏/灭屏后不显示**：这是伪 AOD，不绕过系统锁屏。
3. **USB/ADB 的 Loss 不可测**：显示 `—`，不会伪造 0%。
4. **真实 PCM 波形**：静音显示中心直线；有声时两条线围绕中心独立摆动。若播放时仍为直线，请附诊断信息反馈。
5. 旧版 Receiver 没有常显入口，不影响音频；PC 端不感知。

## 6. 常见问题

- **PC 报 `RECEIVER_UPDATE_REQUIRED`**：手机 APK 的精确哈希不在当前 PC 包的审计表里。请使用与 PC 包配套的 Receiver 版本；每次出包都会升 `versionCode`，避免同版本覆盖失败。
- **`adb install -r` 卡住/失败**：同 `versionCode` 覆盖时，部分手机（如 vivo）会弹“已安装相同版本”，需要手动确认或使用更高 `versionCode` 的新包。
- **Recv 一直是 `—`**：确认会话已认证；首个统计窗口前显示 `—`，已开始统计但没有新数据时显示 0 kbps。
